# Views

Dieser Ordner ist fuer spaetere EJS-Templates vorgesehen.

Moegliche Templates:

- `index.ejs`
- `shop.ejs`
- `product-detail.ejs`
- `guides.ejs`
- `cart.ejs`
- `admin-login.ejs`
- `admin-dashboard.ejs`

Falls eine Seite komplett statisch bleibt, kann sie alternativ in `public/` liegen. Die Entscheidung soll einfach begruendet werden koennen.
