# Views

This folder is reserved for future EJS templates.

Possible templates:

- `index.ejs`
- `shop.ejs`
- `product-detail.ejs`
- `guides.ejs`
- `cart.ejs`
- `admin-login.ejs`
- `admin-dashboard.ejs`

If a page stays completely static, it can alternatively be placed in `public/`. The decision should be easy to justify.
