# Initial Requirements

| Theme | Content |
| :--- | :--- |
| **Project Name** | Tierfutter Shop |
| **Target Audience** | Pet owners, Shop-Team |
| **Initial Situation** | Customers need a clear connection between animal species, life stage, tolerance, and feeding purpose. Currently, a consistent data structure and sufficient consulting guidance in the shop are missing. |
| **Project Goal** | Development of a web-based shop that combines animal worlds, product filters, guides, and comparisons. Manages content via CMS and provides product data via REST-API for external platforms. |
| **Benefit** | Better consultation in the digital buying process, stronger filter logic, visible guides, and consistent product data for external systems. |
