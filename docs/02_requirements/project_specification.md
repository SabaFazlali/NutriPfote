# Pet Food Shop Project Specification

## Overview
- **Name:** Pet Food Shop (NutriPfote)
- **Audience:** Pet owners (B2C), Shop Management Team
- **Goal:** Streamline the digital buying process with data-driven guidance.

## Problem Statement
Customers struggle to find products matching specific health and life-stage needs due to a lack of clear connection between species, life stage, and feeding purpose.

## Goals
1. **Integrated Animal Worlds:** Intuitive entry points for different pets.
2. **Smart Filtering:** Filter by Species -> Life Stage -> Digestibility.
3. **Content Hub:** Guides and product comparisons.
4. **CMS Driven:** Manage content dynamically.
5. **REST API:** Centralized API for data.

## Technical Scope
- **Frontend:** Semantic HTML5, Advanced CSS (Vanilla), Vanilla JavaScript. No frameworks (No React/Vue/Angular).
- **Backend:** Node.js, Express.
- **Data:** JSON files (No SQL/NoSQL databases like MongoDB/MySQL).
- **Security:** JWT Authentication for the Shop Team.
