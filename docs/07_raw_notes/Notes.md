# NutriPfote – My Client Meeting Notes

## Design
- Warm green combined with cream tones, with friendly accent colors

## Requirements – What the Website Offers

### Shop / Products
- Products for animals with comparison functionality
- Product cards with image and text
- Multiple package size variants (e.g. 2 kg, 7 kg, different weights)
- Stock availability display
- Shopping cart
- Ordering process (checkout)
- Filters for products

### Product Detail
- Daily feeding amount per dog weight class
- Feeding and care instructions

### Product Comparison
- Compare products in a table view
- Show category and relevant attributes

### Guides (Ratgeber)
- Guide content with image and text
- Color theme (Leitfarbe) per guide category
- Categories include: allergy, animal profiles, activity/movement profiles
- Filter between different guides
- Allergy-related: if allergic to something, recommend alternative products

### Consultation
- Submit questions via a message form directed to a guide/advisor
- Consultation booking

### Admin / Shop Team Area
- Manage and edit various pages (products, guides)
- Order status and updates
- Stock availability management
- Bulk/supplier stock update
- Guide settings and management

## Technical Constraints
- Backend: Node.js and Express
- Data storage: JSON files only (no database)
- Must be self-implemented (not using pre-built Express templates)
